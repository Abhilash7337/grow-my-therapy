# Grow My Therapy — Stage 2 Practical Assignment

Front-End Developer Internship, Stage 2 (Practical Assignment) for **Grow My Therapy**: clone the homepage of a reference counseling site, then redesign it end-to-end for a fictional therapist — while preserving the original layout.

**What this is:** [conejovalleycounseling.com/home](https://www.conejovalleycounseling.com/home)'s homepage, closely cloned for structure/layout/responsiveness, then redesigned with a new color theme, all-new copy, new photography, and a brand-new "Our Office" section — for **Dr. Maya Reynolds, PsyD**, a fictional licensed clinical psychologist in Santa Monica, CA specializing in anxiety, trauma, and burnout for high-achieving adults.
