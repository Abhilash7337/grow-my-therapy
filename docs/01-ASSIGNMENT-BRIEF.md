## 6. Assignment Breakdown (4 parts, all required)

### Part 1 — Clone the Homepage (UI Accuracy Test) — 25% of grade
Recreate layout, spacing, structure, responsiveness, section order, grid systems, hierarchy. Must work on desktop, tablet, mobile.

**Checklist:**
- [ ] Clone looks exactly like https://www.conejovalleycounseling.com/home in layout/structure
- [ ] Fully responsive (desktop, tablet, mobile)
- [ ] Same fonts, typography, styling as original
- [ ] Reusable theme/colors (Tailwind classes or CSS variables) for easy maintainability
- [ ] Consistent spacing, padding, margins throughout

### Part 2 — Redesign Using Dr. Maya Reynolds' Profile — 25% (theme) + 10% (copy & images)
Three sub-parts, all driven by the profile above:

**A. Theme & Color Palette**
- [ ] Replaced existing theme entirely
- [ ] New primary, secondary, accent colors — cohesive, aesthetically pleasing, different from original
- [ ] All elements (images, backgrounds, text, buttons) consistently use new colors
- [ ] Readable (sufficient contrast) and visually balanced

**B. Copywriting** (rewrite H1s, subtext, button text, services, about, FAQs — all elements)
- [ ] All copy derived from the profile
- [ ] Headings (H1 etc.) include SEO keywords for the main specialty + location (e.g. "anxiety therapy Santa Monica")
- [ ] Services section: **3 services** chosen from the profile, each with a description (e.g. Anxiety & Panic Treatment, Trauma-Informed / EMDR Therapy, Burnout Recovery for High Achievers)
- [ ] About, FAQs, and other sections tailored to profile details
- [ ] SEO-optimized: natural keyword usage, location mentions, best practices

**C. Images**
- [ ] All images replaced — matching new theme/palette
- [ ] Relevant to services/content from the profile, not random stock
- [ ] Feel intentional, support each section's message
- [ ] Maya's picture added + bio written from her profile

### Part 3 — New "Our Office" Section (Creative Thinking Test) — 10%
A brand-new section not in the original template.
- [ ] Section title (e.g. "Our Office", "A Calm Space for Healing")
- [ ] Short supporting copy about the office environment / what clients can expect
- [ ] 2–3 images of the actual office (from the Drive folder)
- [ ] Optional: location mention, in-person/hybrid availability, safety/comfort/privacy emphasis
- [ ] Fits naturally into homepage flow, feels warm/human/trustworthy
- [ ] **[IMP]** Integrates seamlessly with the site's theme, spacing, typography

### Part 4 — Video Walkthrough (Communication Test) — 30% (highest weight!)
- [ ] Exactly ~5 minutes, recorded on Loom
- [ ] Framed as a **client demo to Dr. Maya Reynolds**: "Here's your new website draft"
- [ ] Covers both desktop and mobile walkthroughs
- [ ] Explains design choices and how her profile info was used — in **non-technical language**, benefit-focused
- [ ] Clear, confident spoken English, no jargon
